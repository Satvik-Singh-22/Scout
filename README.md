# Scout — Intelligent Enterprise Data Platform

Scout is an enterprise data intelligence platform that securely bridges the gap between natural language questions and complex database queries. It uses an advanced multi-agent LangGraph pipeline to generate, execute, and synthesize SQL queries into human-readable insights with full Chain-of-Thought transparency.

Built for the **Natwest Hackathon**.

## 🌟 Key Features

- **Multi-Persona Chat**: Seamlessly switch between EXECUTIVE (high-level summaries) and TECHNICAL (precise data details) personas.
- **Agentic Pipeline**: A LangGraph-powered orchestration engine dynamically determines query intent, retrieves schema, generates secure SQL, and synthesizes results.
- **RAG & Unstructured Data**: Full integration with ChromaDB to search through text documents and customer feedback alongside structured databases.
- **Anomaly Detection**: Background scheduled jobs run every 15 minutes to proactively detect data anomalies and threshold breaches.
- **Scheduled Queries**: Set up recurring reports using CRON expressions that deliver right to your dashboard or via email.
- **Data Governance**: Strict row-level access control and team-based table configurations managed by Platform Admins and Data Owners.

## 🏗️ Architecture & Tech Stack

- **Frontend**: Next.js 14, React, Tailwind CSS, Recharts (Deployed on Vercel)
- **Backend API**: FastAPI, Uvicorn, SQLAlchemy (Deployed on Render)
- **Agent Engine**: LangChain, LangGraph, Groq (Llama 3), Ollama (Local Fallback)
- **Database**: PostgreSQL with UUID & JSONB (Hosted on Neon DB)
- **Vector Store**: ChromaDB (Text/Embeddings)
- **Background Jobs**: APScheduler, MailerSend (Emails)

## 🚀 Quick Start (Local Development)

### 1. Prerequisites
- Python 3.10+
- Node.js 18+
- PostgreSQL (or use a cloud provider like Neon)

### 2. Backend Setup
```bash
# Navigate to backend
cd src/backend

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies (or run from root using the synced requirements.txt)
pip install -r requirements.txt

# Configure Environment
cp .env.example .env
# Edit .env with your GROQ_API_KEY, DATABASE_URL, and JWT_SECRET

# Run Migrations
alembic upgrade head

# Start the API
uvicorn main:app --reload --port 8000
```

### 3. Frontend Setup
```bash
# Navigate to frontend
cd src/frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:3000` to access the application.

## 🔒 Security & Compliance
- **Data Protection**: AI agents only receive schema definitions, never raw unstructured database contents unless explicitly requested.
- **SQL Security**: All generated SQL runs through a strict read-only execution agent. No `DROP`, `DELETE`, or `UPDATE` queries are permitted by the AI.
- **Audit Logging**: Every action, chat message, and query generated by the AI is recorded with its full Chain-of-Thought for audit purposes.
